# Historical course material

These files preserve the previous AgentKit-oriented course for reference. They are **outside the current setup and teaching path**. Start with the root README and numbered lessons.

- `agent-builder/`: old visual workflows, screenshots, and supporting retrieval fixtures.
- `chatkit-workflow-app/`: the former Agent Builder workflow-ID integration. Do not use its setup instructions for the new course. The replacement exercise is [ChatKit with your own backend](../optional/chatkit/README.md).
- `agentkit-materials/`: previous slides and handouts, retained as historical artifacts.

The useful triage and retrieval exercises are now preserved as local code in [optional/triage.py](../optional/triage.py) and [optional/retrieval.py](../optional/retrieval.py).

Hosted Evals becomes read-only October 31 and shuts down November 30, 2026; prompt objects also shut down November 30. The core course keeps instructions and evaluation cases in this repository.

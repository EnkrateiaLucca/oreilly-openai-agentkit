2. Responses API — The Primitive
Key Innovations
  • Items-based I/O — polymorphic output: text, tool calls, reasoning
  • Server-side state via previous_response_id
  • Reasoning preservation across conversation turns
  • Replaces Chat Completions API and Assistants API
Built-in Tools
  • web_search_preview — live web search
  • file_search — RAG over uploaded files
  • code_interpreter — Python sandbox
  • computer_use_preview — GUI automation
  • mcp — Model Context Protocol servers
Basic Call
from openai import OpenAI
client = OpenAI()

response = client.responses.create(
    model="gpt-4o",
    input="Summarize the latest AI news",
    tools=[{"type": "web_search_preview"}]
)
print(response.output_text)
Multi-turn (Server-side State)
from openai import OpenAI
client = OpenAI()

r1 = client.responses.create(
    model="gpt-4o",
    input="What is the Responses API?"
)
# Continue — server manages history:
r2 = client.responses.create(
    model="gpt-4o",
    input="Give me a code example",
    previous_response_id=r1.id
)
3. Agents SDK — The Framework
5 Core Primitives  pip install openai-agents
  • Agents — LLM + tools + instructions
  • Runner — automated agent loop execution
  • Handoffs — multi-agent delegation
  • Guardrails — parallel input/output validation
  • Tracing — built-in observability (spans, traces)
Use SDK When…
  • Custom server-side state management
  • Human-in-the-loop approval flows
  • Fine-grained tool execution control
  • Multi-runtime or non-OpenAI deployment
  • Full code ownership required
Basic Agent + Runner
from agents import Agent, Runner

agent = Agent(
    name="Research Assistant",
    instructions="You are a research assistant.",
    model="gpt-4o",
    tools=[web_search]
)

result = await Runner.run(
    agent, "Summarize recent AI papers"
)
print(result.final_output)
Multi-agent Handoffs
from agents import Agent, Runner

billing = Agent(name="Billing Agent", ...)
technical = Agent(name="Tech Agent", ...)
general = Agent(name="General Agent", ...)

triage = Agent(
    name="Triage",
    instructions="Route to the right agent.",
    handoffs=[billing, technical, general]
)

result = await Runner.run(
    triage, "I can't access my invoice"
)
4. AgentKit Platform — The Product Layer
Agent Builder
Visual drag-and-drop canvas for composing multi-step agent workflows — no orchestration glue code. Versioned, publishable workflows with per-node traces and interactive preview testing.
ChatKit
Embeddable React component + Web Component chat UI. Handles auth, streaming, file upload, tool invocation display, chain-of-thought visualization, and suggestion chips.
Connector Registry
Pre-built data connectors: Dropbox, Google Drive, SharePoint, and any MCP server. Add as a node in any workflow — no custom integration code needed.
Evals for Agents
Trace grading, dataset building from live runs, and automated prompt optimization. Closes the Build → Test → Deploy → Measure → Improve cycle.
5. Agent Builder — Node Types
Start
Entry point — accepts initial user input
Agent
Calls an LLM with instructions + tools
Classifier
Routes to one of N branches by output category
If / Else
Conditional logic on data values
File Search
Vector search over uploaded documents (RAG)
Transform
Maps data between incompatible node outputs/inputs
MCP
Calls a hosted MCP server tool (3rd-party data/actions)
Guardrails
Input/output safety validation before/after agents
End
Returns final output to the caller
Guardrails Protect Against
  • PII detection — Block or Redact mode
  • Jailbreak attempts
  • Prompt injection attacks
  • Off-topic / out-of-scope requests
  • Sensitive data leakage in responses
Versioning & Deployment
  • Each version: stable ID + immutable graph snapshot
  • Safe rollbacks — prior versions stay accessible
  • Staged promotion: dev → staging → prod
  • ChatKit — embed in minutes, point at workflow ID
  • SDK Export — Python/TS for custom server control

Key Takeaways
  • Start with Responses API — maximum control & deepest learning; replaces Chat Completions API + Assistants API (March 2025)
  • Add Agents SDK when you need multi-agent orchestration, handoffs, guardrails, and built-in tracing
  • Use Agent Builder for visual workflow composition — great for non-dev teams, rapid prototyping, and Evals in the UI
  • Deploy via ChatKit when shipping to real users — auth, streaming, and file upload are handled for you
  • Each layer builds on the previous — prototype in Agent Builder, export to SDK for production; no vendor lock-in at SDK level
